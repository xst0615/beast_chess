# beast_chess

斗兽棋是一款经典的二人对弈棋类游戏。它的棋盘横七列、纵九行，中部有两片水域（小河），双方底线各有三个呈 “品” 字形排列的陷阱和一个兽穴 。

以下是斗兽棋的核心规则：

## 1. 棋子与等级

双方各有 8 只动物棋子，战斗力由强到弱依次为：**象 > 狮 > 虎 > 豹 > 狼 > 狗 > 猫 > 鼠** 。

---

## 2. 走法与吃子

* **基础走法**：红方先走，双方轮流走棋。每只兽每次只能走一格（前后左右均可），但不能进入己方的兽穴 。
* **普通吃子**：强者可以吃掉弱者；同类动物相遇时，可以互相吃掉 。
* **特殊吃子（鼠吃象）**：老鼠是唯一可以吃掉大象的动物（大象不能吃老鼠） 。
* **陷阱吃子**：当敌方的兽走入己方陷阱时，会失去战斗力，此时己方的任意兽都可以将其吃掉 。

---

## 3. 特殊动物走法

* **狮、虎跳河**：在河边时，可以纵向或横向直接跳过小河，并吃掉对岸较弱的敌方动物。但如果河中有老鼠（无论敌我）阻隔了跳跃路线，则不能跳；若对岸是比自己战斗力强的兽，也不可以跳过 。
* **鼠入水中**：老鼠是唯一可以走入小河的动物，在水中的走法与陆地一致（每次一格）。陆地上的其他兽不能吃河中的鼠，河中的鼠也不能吃陆地上的象。两只老鼠在河中相遇时可以互吃 。

---

## 4. 胜负判定

满足以下任一条件即可判定胜负：

* **胜利**：任何一方的兽走入敌方的兽穴；或对方的兽被吃光；或对方所有活着的兽被完全困住无法移动 。
* **和棋**：在连续 100 回合内，双方均无动物被吃；或在双方同意的情况下可和棋 。
